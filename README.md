# 演化我的世界

一个可在浏览器里玩的迷你方块世界：村民带有可遗传基因，会自己觅食、砍树、盖屋、交配，并在饥荒与衰老中被自然选择。

## 安装成 Mac 应用

在项目目录执行：

```bash
npm install
npm run pack
```

完成后，应用在 `release/mac-arm64/演化我的世界.app`（Intel 芯片则在 `release/mac`）。把它拖进「应用程序」文件夹即可。第一次打开如果被系统拦住，在 Finder 里右键这个 App，选择「打开」。

浏览器里试玩：

```bash
npm run dev
```

## 操作

按 Esc 松开鼠标，才能拖动滑杆和点名单。

| 按键 | 作用 |
| --- | --- |
| WASD | 移动 |
| 空格 | 跳跃 |
| 鼠标 | 视角（点击画面锁定） |
| 左键 / 右键 | 挖方块 / 放泥土 |
| E | 冲刺 |
| F | 选中准星附近的人 |
| R | 投放新村民 |
| T | 在附近投食（浆果） |
| P | 暂停时间与人物 |
| 左下角滑杆 | 拖动当前时刻、时间流速、人物行动速度 |

## 怎么看生死和轨迹

- 头顶绿字是活人，并写着当前行为（觅食、筑巢、睡觉、社交）。
- 倒在地上、头顶灰字的是死者。左侧可以切换「活着 / 死亡」。
- 点一个人之后，下方按时间列出从出生到死亡的记录。点某一条，会走到事情发生的地点。
- 「显示路线」只画出这一个人的路，避免满屏线条。
- 靠近的人会冒出对话气泡，右侧「对话」里也有记录。

## 干预命运

选中一个人后，右下角可以喂饱、让他休息、给木头、护佑（暂时不会饿死或老死）、传到身边、走到他身边、终结，或把死者复活。基因滑杆会立刻改写这个人的性状。

## 演化机制

每个村民有 8 个基因：速度、觅食、筑巢、社交、勇敢、节食、生育、视力。

- 饿了会优先找浆果；节食高的人饿得慢
- 筑巢欲高的人会砍树搭木板屋，夜里更爱回家
- 社交和生育高的人更容易交配产下后代
- 后代基因来自父母的交叉遗传，并带有少量突变
- 饿死或老死会把不适应的基因从种群里清掉

右侧面板会实时显示当前种群的平均基因，便于观察几天后性状是否发生漂移。
